# IMPLEMENTATION_PLAN.md — pakistan-board-results-analysis

Small project. Roughly **2–3 weeks at 5–6 hrs/week**, alongside studies.
Grades come first — if exams are close, pause this project.

| Week | Phases | Milestone |
|---|---|---|
| 1 | 0–2 | Sources documented, raw tables collected |
| 2 | 3–5 | Tidy table + tests, questions fixed, charts drafted |
| 3 | 6–9 | Findings written, walkthrough done, README + Kaggle ready |

## Dependency notes
- Data finding (Phase 1) is the biggest risk. If no good aggregate source
  exists for a board/year, narrow the scope (fewer boards, fewer years)
  rather than inventing data. Document the narrowing.
- Fix the questions (Phase 4) before looking at results charts.
- PDF extraction can be messy — always spot-check extracted numbers against
  the original PDF.
